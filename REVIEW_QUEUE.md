# Review queue to keep out of the silent default path

These items should not stop the first build, but they should remain visible as review-sensitive branches.

1. **Spread-footing value conflict**
   - source library includes both 100 kPa and 140 kPa families
   - working default for MVP: 140 kPa branch
   - app behavior: generate with review metadata where needed; do not silently alternate

2. **Engineered fill by others / unknown provenance**
   - professional-risk wording
   - may reference outdated internal process / named reviewer
   - app behavior: mark as review-required

3. **24-inch and rarer as-constructed branches**
   - 18-inch and 20-inch can be implemented first
   - 24-inch path should be review-gated until exact wording is confirmed

4. **Complex remediation packages**
   - rain-softened variants
   - fillcrete follow-up variants
   - ground-heating wording
   - app behavior: keep branches but show review badge

5. **Special advisories**
   - garden suite
   - garage slab organics
   - slab disclaimer
   - building addition
   - app behavior: special-case section with review flags

6. **Standard vs modified trigger threshold closure**
   - clause family exists
   - exact complete office rule is not fully locked
   - app behavior: implement stable known cases and flag uncertain combinations
